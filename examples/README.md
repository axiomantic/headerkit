# HeaderKit Examples

This directory contains real-world binding examples generated by HeaderKit across diverse C and C++ libraries in audio, networking, and plugin architectures.

## Layout

```text
examples/
├── generate_all.py         # Python script to regenerate all bindings via HeaderKit API
├── headers/                # Vendored or standalone C/C++ header dependencies (e.g. CLAP)
└── nim/                    # Nim bindings and idiomatic wrappers
    ├── rtmidi/             # RtMidi FFI + RAII wrappers + runnable example
    ├── rtaudio/            # RtAudio FFI + RAII wrappers + audio hardware probe
    ├── nng/                # NNG Scalability Protocols FFI + inproc messaging demo
    └── clap/               # CLAP audio plugin spec FFI + DSL plugin template
```
